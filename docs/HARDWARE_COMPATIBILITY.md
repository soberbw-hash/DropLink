# 支持的网卡

DropLink 使用一张专用 USB 无线网卡接收 iPhone 的隔空投送。当前已验证 **Realtek RTL8811CU**，硬件 ID 为 `USB\VID_0BDA&PID_C811`。

在 Windows **设备管理器 → 网卡 → 属性 → 详细信息 → 硬件 ID** 中查看型号。首次配置会将这张卡切换到 WinUSB，电脑上网请使用有线网络或另一张网卡。

使用时只连接一张匹配的专用网卡。同时插入多张时，接收程序会提示无法唯一定位网卡；拔下多余网卡后可重试。RTL8821CU 复合设备和其他芯片尚未通过本项目验证。
